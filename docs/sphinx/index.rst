HireSense API Documentation
===========================

Welcome to the HireSense API documentation. This documentation is automatically generated from Python docstrings in the codebase.

**HireSense** is an AI-powered resume intelligence and career path recommendation system that uses semantic analysis and transformer-based NLP models to understand resumes beyond simple keyword matching.

Features
--------

* Semantic resume parsing using transformer models
* Context-aware skill extraction from projects & tech stack
* Automatic structuring of unstructured resume data
* Role-based benchmarking and profile comparison
* Personalized learning paths for upskilling & career switching
* Skill gap detection with recommendations

Architecture
------------

HireSense follows a modular architecture with clear separation of concerns:

* **Models** - Database models and ORM definitions
* **Views** - Route handlers and request processing
* **Services** - Business logic and NLP processing
* **Utilities** - Helper functions and CLI commands
